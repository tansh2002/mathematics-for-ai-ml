## Evaluating an Expression with Variables

To **evaluate** an algebraic expression means to find its numerical value by replacing the variable with a given number (substitution) and computing the result using standard order of operations.

---

### The Problem Scenario

* **Context:** A local hospital holds a raffle as a fundraiser [[00:00](https://www.google.com/search?q=https%3A%2F%2Fwww.youtube.com%2Fwatch%3Fv%3DAJNDeVt9UOo%26t%3D0)].
* **Expression:**

$$5t + 3$$


* **Meaning of components:**
* $t$ = variable representing the **number of tickets** purchased [[00:06](https://www.google.com/search?q=https%3A%2F%2Fwww.youtube.com%2Fwatch%3Fv%3DAJNDeVt9UOo%26t%3D6)].
* $5t$ = $\$5 \text{ per ticket}$ ($5 \times t$).
* $3$ = a fixed fee or entry charge.


* **Goal:** Evaluate the expression for $t = 1$, $t = 8$, and $t = 10$ [[00:23](https://www.google.com/search?q=https%3A%2F%2Fwww.youtube.com%2Fwatch%3Fv%3DAJNDeVt9UOo%26t%3D23)].

---

### Step-by-Step Evaluations

#### Case 1: When $t = 1$ [[00:23](https://www.google.com/search?q=https%3A%2F%2Fwww.youtube.com%2Fwatch%3Fv%3DAJNDeVt9UOo%26t%3D23)]

1. **Substitute:** Replace $t$ with $1 \implies 5(1) + 3$ [[00:32](https://www.google.com/search?q=https%3A%2F%2Fwww.youtube.com%2Fwatch%3Fv%3DAJNDeVt9UOo%26t%3D32)]
2. **Multiply:** $5 \times 1 = 5$ [[00:49](https://www.google.com/search?q=https%3A%2F%2Fwww.youtube.com%2Fwatch%3Fv%3DAJNDeVt9UOo%26t%3D49)]
3. **Add:** $5 + 3 = \mathbf{8}$ [[00:57](https://www.google.com/search?q=https%3A%2F%2Fwww.youtube.com%2Fwatch%3Fv%3DAJNDeVt9UOo%26t%3D57)]

---

#### Case 2: When $t = 8$ [[01:03](https://www.google.com/search?q=https%3A%2F%2Fwww.youtube.com%2Fwatch%3Fv%3DAJNDeVt9UOo%26t%3D63)]

1. **Substitute:** Replace $t$ with $8 \implies 5(8) + 3$ [[01:12](https://www.google.com/search?q=https%3A%2F%2Fwww.youtube.com%2Fwatch%3Fv%3DAJNDeVt9UOo%26t%3D72)]
2. **Multiply:** $5 \times 8 = 40$ [[01:22](https://www.google.com/search?q=https%3A%2F%2Fwww.youtube.com%2Fwatch%3Fv%3DAJNDeVt9UOo%26t%3D82)]
3. **Add:** $40 + 3 = \mathbf{43}$ [[01:29](https://www.google.com/search?q=https%3A%2F%2Fwww.youtube.com%2Fwatch%3Fv%3DAJNDeVt9UOo%26t%3D89)]

---

#### Case 3: When $t = 10$ [[01:29](https://www.google.com/search?q=https%3A%2F%2Fwww.youtube.com%2Fwatch%3Fv%3DAJNDeVt9UOo%26t%3D89)]

1. **Substitute:** Replace $t$ with $10 \implies 5(10) + 3$ [[01:34](https://www.google.com/search?q=https%3A%2F%2Fwww.youtube.com%2Fwatch%3Fv%3DAJNDeVt9UOo%26t%3D94)]
2. **Multiply:** $5 \times 10 = 50$ [[01:49](https://www.google.com/search?q=https%3A%2F%2Fwww.youtube.com%2Fwatch%3Fv%3DAJNDeVt9UOo%26t%3D109)]
3. **Add:** $50 + 3 = \mathbf{53}$ [[01:55](https://www.google.com/search?q=https%3A%2F%2Fwww.youtube.com%2Fwatch%3Fv%3DAJNDeVt9UOo%26t%3D115)]

---

### Summary of Results

| Tickets Purchased ($t$) | Substitution ($5t + 3$) | Total Cost |
| --- | --- | --- |
| **$1$** | $5(1) + 3$ | **$\$8$** |
| **$8$** | $5(8) + 3$ | **$\$43$** |
| **$10$** | $5(10) + 3$ | **$\$53$** |

---

### Key Takeaway for Notes

* **Substitution rule:** Wherever the variable appears, swap it out with the target value (placing it in parentheses helps prevent arithmetic errors).
* **Order of operations:** Multiplication ($5 \times t$) must always be calculated before the addition ($+ 3$) [[00:49](https://www.google.com/search?q=https%3A%2F%2Fwww.youtube.com%2Fwatch%3Fv%3DAJNDeVt9UOo%26t%3D49)].
